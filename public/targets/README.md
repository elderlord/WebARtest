# 이미지 타겟 슬롯

패널 정면 사진에서 컴파일한 **이미지 타겟**을 이 폴더에 둔다.

## 절차 (사진 확보 후)

1. 패널을 정면·균일 조명에서 촬영 (유광 패널은 글레어 회피). 고해상도 원본 확보.
2. `image-target-cli`로 컴파일:
   - 저장소: `github.com/8thwall/8thwall` (apps/image-target-cli, MIT)
   - 입력: 패널 정면 이미지 → 출력: 타겟 디스크립터
3. 컴파일된 타겟을 이 폴더에 넣고, 타겟 이름을 코드에 반영:
   - `src/ar/xr8.js`의 `IMAGE_TARGET_NAME`을 실제 타겟 이름으로 교체
   - 여러 패널이면 `XR8.XrController.configure({ imageTargets: [...] })`에 배열로 등록

## 동시 로드 개수 (문서 §6)

한 세션에 몇 개의 타겟까지 안정적으로 물릴 수 있는지는 실측 대상이다.
10개 패널이 한 번에 안 되면 전시 구역별로 타겟 세트를 분할 로드한다.
