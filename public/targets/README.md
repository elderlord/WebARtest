# 이미지 타겟

앱은 `manifest.json`에 적힌 이름을 읽어 각 `<name>.json`을 런타임에 로드하고,
`XR8.XrController.configure({ imageTargetData: [...] })`로 주입한다
(`src/ar/xr8.js`의 `loadImageTargets`).

```
manifest.json          { "targets": ["target0b"] }
<name>.json            image-target-cli 메타데이터
<name>_luminance.png   추적에 실제로 쓰이는 그레이스케일 이미지
```

`<name>.json`의 `imagePath`는 CLI 기본값이 `image-targets/…`라서, 로더가 실제
서빙 경로(`<base>/targets/<file>`)로 교정한다.

## 현재 타겟

### `target0b` — 0-B 테스트 타겟 (자체 생성, v2)

`target0b.png`가 원본이다. A4(210×297mm) 용지에 인쇄하되, **추적 영역은
인쇄된 검은 테두리와 정확히 일치하는 180×240mm(3:4)** 다.

> **왜 3:4인가**: 엔진의 trackable region은 3:4(portrait) 또는 4:3(landscape)
> 고정이다(luminance가 항상 480×640). 따라서 A4 전체(1.414)는 타겟이 될 수 없고,
> CLI 기본 크롭은 위아래를 잘라낸다. v1은 이 때문에 정합박스와 종이 비율이
> 어긋나 보였다. v2는 3:4 영역을 명시적으로 그리고 컴파일 시 그 영역을 크롭으로
> 지정해 **인쇄 테두리 = 추적 영역 = 정합 박스**가 되도록 했다.
>
> 컴파일 값: `top=168 left=88 width=1063` (높이는 3:4로 자동=1417) → 180×240mm

포함 요소와 의도:

| 요소 | 목적 |
|---|---|
| 인쇄 테두리 | **추적 영역과 동일**. 정합박스가 이 선에 겹쳐야 정상 → **정합 오차 측정 기준** |
| 비대칭 코너 마커(22/16/12/8mm) | 회전 모호성 제거 |
| 비반복 고대비 도형 다수 | 추적 특징점 공급 |
| 제목급 큰 글자 3개(생각/중/실측) | 0-D 단어 정합 probe 예행 대상 |
| 100mm 눈금자 | **world scale calibration**(스펙 §6.2) 교차검증 |

**사용법**: `<사이트>/targets/target0b.png`를 열어 **A4에 100% 배율로 인쇄**한다.
인쇄하면 추적 영역 폭이 180mm로 확정되어 거리·스케일 검증이 가능하다.
(모니터 표시는 반사·모아레·백라이트 때문에 인식 거리가 실제보다 짧게 나온다 —
0-B 실측에서 모니터 대비 인쇄물의 인식 거리가 뚜렷이 길었다.)

### `poster` — 생각중 특별전 포스터 (사용자 제공)

아트워크 `세로형 포스터.jpg` (640×940 px, 가로세로비 **1.469**).

**주의 — 정합 박스는 포스터 외곽과 일치하지 않는다.** 엔진 추적 영역이 3:4(1.333)
고정이라 1.469 비율 전체를 담을 수 없어, 기본 크롭이 세로 중앙 4:3 영역만 취한다
(`top=44 height=853`, 가로는 전체 640).

정상 동작 시 박스는:
- **좌우: 포스터 가장자리와 딱 맞음** (가로는 전체 폭이 추적 영역)
- **위아래: 안쪽으로 들어감** — 인셋 = 포스터 높이의 약 6.8%
  (예: 폭 420mm 포스터라면 위아래 각 ≈29mm 안쪽)

이는 오류가 아니라 3:4 제약의 결과다. `target0b`처럼 테두리를 그려 넣을 수 없는
기성 인쇄물에서는 이 형태가 정상이며, **정합 오차는 좌우 가장자리와 단어 probe로
판단**한다.

`manifest.json`의 `widthMm`은 **인쇄물의 실제 가로 폭**을 넣는다(스케일 환산 기준).

## 새 타겟 추가

```bash
npx @8thwall/image-target-cli@latest      # 이미지 경로 → flat → 크롭 → 출력폴더 → 이름
```
산출물 중 `<name>.json`과 `<name>_luminance.png`를 이 폴더에 넣고
`manifest.json`의 `targets` 배열에 이름을 추가한다.
(원본/크롭/썸네일은 추적에 불필요하며 용량만 차지한다)

## 동시 로드 개수 (계획서 §6)

한 세션에 몇 개까지 안정적으로 물릴 수 있는지는 실측 대상이다. 10개 패널이 한 번에
안 되면 전시 구역별로 타겟 세트를 분할 로드한다.
