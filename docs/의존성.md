# 외부 라이브러리 및 의존성 인벤토리

기준: 2026-09-08 / 브랜치 `claude/webar-panel-text-emphasis-jt4uwf`

국립중앙과학관 납품 검토를 전제로, **런타임에 실제로 실려 나가는 것**과
**개발·검증 과정에서만 쓰는 것**을 분리해 정리한다. 라이선스 위험은
사실상 한 곳(8th Wall 바이너리)에만 집중되어 있다.

---

## 1. 앱 런타임 — 최종 산출물(dist)에 포함

| 이름 | 버전 | 라이선스 | 배포 방식 | 비고 |
|---|---|---|---|---|
| **three.js** (`three`) | ^0.160.0 (lock 0.160.1) | MIT | npm → 번들 | 유일한 production npm 의존성 |

`three`는 보수적으로 0.160에 고정해 두었다. XR8의 `Threejs` 파이프라인 모듈이
`window.THREE`를 요구하고 내부적으로 특정 버전대를 가정하므로,
버전을 올릴 때는 반드시 실기기에서 재검증해야 한다.

## 2. 앱 런타임 — CDN에서 지연 로드 (번들 외부)

| 이름 | 버전 | 라이선스 | URL |
|---|---|---|---|
| **8th Wall XR Engine (Distributed Binary)** | `@8thwall/engine-binary@1` | **XR Engine License Agreement (Niantic Spatial)** | `https://cdn.jsdelivr.net/npm/@8thwall/engine-binary@1/dist/xr.js` |
| └ `slam` chunk | 동일 | 동일 | 엔진이 `XR8.loadChunk('slam')`으로 자동 로드 |
| └ `resources/powered-by.svg` | 동일 | 동일 | §1.3 귀속표시 마크 |

- 선언 위치: `src/ar/runtime.js` (`RUNTIME.url`), `src/ar/attribution.js`
- **npm 설치도, git 커밋도 하지 않는다.** Niantic 공식 배포본을 원형 그대로
  참조하는 것이 라이선스상 가장 깨끗하기 때문 (`.gitignore`에 `public/xr8/*` 제외).
- `XrController`(트래킹)는 core `xr.js`가 아니라 **slam chunk 안에** 있다.
  이미지 타겟만 쓰더라도 chunk 로드가 필수다.

### ⚠️ 라이선스 리스크 — 유일한 법적 게이트

XR Engine License Agreement는 MIT가 아니다. 프로덕션 전 기관 법무 검토가 필요하다.

- **§1.2**: *(1) 유료 또는 대가를 받고 제공되며 (2) 그 가치가 전적으로 또는
  실질적으로 본 소프트웨어의 기능에서 파생되는* 제품/서비스에는 사용 금지.
  → 무상 공개 전시 서비스라면 통과 가능성이 높으나, **기관이 판단할 사안**이다.
- **§1.2(i)(ii)**: 리버스 엔지니어링·디컴파일·디스어셈블 금지, 개작·2차적저작물 금지,
  배포는 원형 그대로만. → 본 프로젝트는 `xr.js`를 디컴파일하지 않고
  공개 문서화된 API만 사용한다.
- **§1.3**: 바이너리 사용 시 귀속표시 필수 → `src/ar/attribution.js`로 구현 완료.
- 8th Wall 호스팅 플랫폼은 2026-02-28 종료, 기존 배포는 2027-02-28까지 동작.
  우리는 호스팅을 쓰지 않고 self-host이므로 이 일정에 직접 묶이지는 않는다.

### 경로 B(MIT) 탈출구

`8thwall/8thwall` 저장소의 `packages/engine`은 **MIT**로 공개되어 있다.
`src/ar/runtime.js`의 `RUNTIME` 객체 하나만 교체하면 앱 코드 수정 없이 전환된다
(url 교체 / `requiresAttribution=false` / `hasSlamChunk=false`).
단, **MIT 빌드에는 닫힌 SLAM이 빠져 있다** — 월드 트래킹 연속성이 필요하면
경로 A를 유지하거나 대체 수단이 필요하다.

| 이름 | 버전 | 라이선스 | 용도 |

  `pip install "opencv-python-headless<5" pillow`

## 6. 검토했으나 채택하지 않음

| 후보 | 판단 |
|---|---|
| **OpenCV.js** | E3(실시간 원거리 발견) 프로토타입 후보. wasm 약 8~10MB — 현장 Wi-Fi 조건(계획서 §6)과 충돌 가능. **0-C 판정 전에는 착수 금지.** |
| **WebXR (`immersive-ar`)** | iOS Safari 미지원 → 관람객 절반이 못 씀. 공간 연속성은 XR8 SLAM으로 대체. |
| `xr-face.js` chunk | 본 프로젝트와 무관, 로드하지 않음. |
| AR.js / MindAR | 검토 단계에서 8th Wall 대비 이미지 타겟 안정성이 떨어져 제외. |

## 7. 정리

- 우리가 직접 쓰는 **런타임 코드 의존성은 사실상 2개**뿐이다: three.js(MIT)와
  8th Wall 엔진 바이너리(XR Engine License).
- 나머지는 전부 빌드·CI·오프라인 분석 도구이며 납품물에 포함되지 않는다.
- **법적 검토가 필요한 항목은 8th Wall 바이너리 하나**이고,
  MIT 경로 B라는 대체 경로가 코드 수준에서 이미 준비되어 있다.
