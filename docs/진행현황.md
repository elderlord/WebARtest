### 0-A 확정 사실 (2026-08-07 조사 + 바이너리 실물 확인)

- self-host = `xr.js`를 벤더링, `<script async src="./xr.js">`로 로드
  (구 `apps.8thwall.com/xrweb` 클라우드 스크립트 대체). 계획서 §8 선례와 일치.
- 획득 경로: `@8thwall/engine-binary` (jsdelivr CDN / npm), `github.com/8thwall/engine`.
  사용자가 `xrstandalone.zip`(xr.js + xr-slam.js + xr-face.js + resources + LICENSE) 제공.
- **SLAM은 chunk**: `data-preload-chunks="slam"` / `XR8.loadChunk('slam')`, 바이너리에 포함.
- **⚠ 라이선스 정정**: 이 바이너리는 **MIT가 아니라 XR Engine License Agreement**
  (Niantic Spatial). §1.2 — *유료이면서 그 가치가 소프트웨어 기능에서 상당 부분
  파생되는* 서비스엔 사용 불가(두 조건 모두 충족 시). 과학관 전시 적용은 **기관 법무
  검토**. 귀속표시("Powered by 8th Wall") 필수. 리버스 엔지니어링·수정 금지.
  → "MIT-only면 라이선스 회피"는 **MIT 소스 직접 빌드 경로에서만** 성립. 상세: 스펙 §3.3.
- 카메라 텍스처 셰이더 접근(shimmer 생사)은 **런타임 벤더링 후 실측** 필요.
- 상세: `public/xr8/README.md`, 스펙 §3.3
