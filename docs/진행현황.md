## 4. 구축한 것 — 0단계 계측 하네스

커밋 `88da163`. Vite + three.js + 8th Wall Image Targets(MIT).
계획서 §9.2 준수: **효과(1단계) 미구현, 0단계 실측 도구만.**

- **정합 확인용 와이어프레임 박스**(효과 아님, 정합 오차 측정용 자)
- **계측 HUD**: 인식 상태 / 거리(cm) / 기울기(°) / 정지 지터(mm) 실시간 노출
  → §5 4개 측정 항목을 화면에서 바로 판독
- **DEV(mock) 모드**: 런타임·타겟 없어도 실기기 셸 점검 가능
- **HTTPS dev 서버**(basic-ssl): 폰 LAN 실측 지원

검증: `npm run build` 통과(11모듈), dev 서버 HTTPS 200 확인.

### 의도적으로 비워 둔 슬롯 (오프라인 미확정, 추측 금지)

1. `public/xr8/` — self-host XR8 런타임. 클라우드 종료로 직접 벤더링 필요.
   가짜 URL을 넣지 않고 슬롯 + README로 남김.
2. `public/targets/` — 컴파일 이미지 타겟. 패널 사진 미확보가 원인.
